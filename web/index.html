Research tools — batch, deleted diff, citations

For teams, researchers and newsrooms. Batch runs the same archive search across many handles; deleted diff checks each post live and marks it live / deleted / unknown; citations turn the results on screen into a citable list. Same archive, same tier caps, same honest limits — Trust & safety.

One target per line: NETWORK @handle — e.g. x jack, instagram nasa. Lines starting with # are comments. Your tier runs up to its batch cap at a time (Free: 3 · Starter: 10 · Pro: 50 · Studio: 200) — extra lines wait for the next run.

One handle, one network — each archived post is checked live and marked live, deleted, or unknown. Unknown means the live site was login-walled or errored — it is never counted as deleted. Every row keeps its Wayback snapshot link. Deleted diff is a Starter feature (free tier: search + CSV only).

Build a citable list from the results already on screen — a deleted-diff run's verdicts, or a plain search's captures. Each citation carries the archived URL, the Wayback timestamp, the snapshot link, the live verdict, and the retrieval date.

Triage, not court-ready. Found ≠ guilty. Not found ≠ not real. A citation proves a post existed on the archived date — not who wrote it, why it was deleted, or intent. Verify each snapshot yourself at web.archive.org before relying on it in a filing.
