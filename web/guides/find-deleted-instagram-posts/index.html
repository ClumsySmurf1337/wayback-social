How to find deleted Instagram posts

Instagram is the hardest network in this tool to list per user. Here's what the archive actually holds — and the single-post check that works instead.

← Back to search · My dashboard · All guides

The short version

Instagram post URLs look like instagram.com/p/ABC123/ — the code, not the handle. Because the handle isn't in the URL, the archive can't list "all posts by @nasa" the way it can for X. A per-user Instagram search returns mostly profile-page captures (the profile as it looked on a date), not a list of individual posts. That is a property of Instagram's URLs, not a bug in the search — and any tool that promises a full per-user Instagram post list from the archive is overselling.

What to do instead

  1. Search the handle anyway. On the search console, pick Instagram, type the handle, set a date range. You will get profile captures with dates — useful for "what did this profile look like, and when did it change", and for old bios.
  2. Check one post at a time. If you know the post's URL (instagram.com/p/<code>/), paste it into the single post URL field on the search console — the console checks that one post across the archives and labels each capture with its source. (You can still open the URL on the Wayback Machine directly if you prefer: paste it into the search box at web.archive.org.) This is the reliable check for a specific deleted post — the console's per-user search is the wrong tool for it, because it searches by handle, not by single post URL.
  3. Try the other archives. Ghostarchive saves Instagram posts other archives miss, including playable video, and archive.today renders JavaScript in a real browser, so its captures often read where Wayback replays are blank shells. Both are outbound links from a result — check them one URL at a time, and never treat an archive.today capture as legal evidence (it is blacklisted by Wikipedia and 429s aggressively).
  4. Run the deleted diff on what you find. Deleted diff (Starter and up) checks each archived post live. For Instagram there is no free no-login live check — the network is login-walled — so verdicts for Instagram posts are usually unknown, which is never counted as deleted.

What CDX can and can't do for Instagram

  • Can: profile-page captures with dates; single-post captures when you know the exact /p/<code>/ URL; old bios and profile changes over time.
  • Can't: enumerate "every post this handle published" — the URLs don't carry the handle, so there is nothing to enumerate by. Reels and stories are barely archived at all; stories almost never.
  • Patchy: many Instagram captures replay as blank shells — the post text may still be in the page source. Private accounts are never captured.
  • Live checks: none free. Instagram, Facebook, Threads and LinkedIn are all login-walled for live reads. The tool labels Instagram live checks as archive-only rather than pretending.

Coverage label: moderate. The console labels every network honestly — X, Reddit, Bluesky and Mastodon are good; Instagram, Facebook, TikTok, YouTube, Threads, Tumblr and Twitch are moderate; LinkedIn, Pinterest and Medium are poor. A thin result for Instagram is the archive telling the truth, not the search failing.

Honest limits

Public archived posts only. Found ≠ guilty. Not found ≠ not real.

A missing Instagram post was most likely never captured — not necessarily never posted, and not proof of anything about the person. Do not use results to harass, stalk, or confront anyone, and never look up anyone under 18. Trust & safety
