Changelog v1.2–v1.5

Everything that shipped on 26 November 2026 — the day the tool went from a one-network script to a 14-network archive search with deleted diffs, evidence packs, and a web console.

← Back to search · My dashboard · All guides

v1.5 — live crawling, more archives, web tiers, CDX proxy

  • Live crawling: Bluesky and Mastodon public APIs, YouTube oEmbed and channel RSS, X/TikTok oEmbed existence checks — the live half of the deleted diff. Reddit live is dead without OAuth, and stays labelled archive-only.
  • More archives: Arquivo.pt full-text and CDX search, Ghostarchive result parsing with capture dates, MemGator multi-archive TimeMaps, Common Crawl as async jobs only (its index 504s too often for the live path).
  • Web tiers that work: licence keys checked in the browser, per-tier caps enforced in the search, export formats gated by tier, and a dashboard with usage, history, and a licence box.
  • CDX proxy: the live site's search used to fail on archive.org CORS and fall back to demo data. A Pages Function now proxies CDX same-origin — the search on the deployed site is real.
  • Analytics: Cloudflare Web Analytics (free, cookieless) + a weekly SEO report format. Never tracks searched handles, results, or keys.

v1.4 — live checks, Arquivo, evidence pack

  • Bluesky / Mastodon live checks with feed-completeness verdicts, wired into the deleted diff.
  • Arquivo.pt keyword search (Pro) and CDX mode — the one archive with real full-text search.
  • Evidence-pack ZIP (Studio): report.html, captures, and a SHA-256 manifest. Two bugs found by live testing and fixed on the way: a Mastodon URL bug that faked a "deleted" verdict, and a README that pointed at the wrong manifest file.
  • Export-format gating enforced: Free exports CSV only; Starter adds JSON; Pro adds JSONL/HTML; Studio adds the evidence pack.
  • Playwright end-to-end suite added, run against the local site.

v1.3 — pricing v1.3, licence keys

  • Studio is a finite pack: 10 evidence-pack reports, batch 200, 25,000 captures per search, 10,000 text fetches, 5 seats. No tier is sold as uncapped — a test enforces it.
  • Launch vs regular pricing: launch Starter $9 / Pro $19 / Studio $49 / Bundle $59; regular $19 / $29 / $99 / $147. Bundle math corrected — the v1.2 total was wrong ($137); the real regular total is $147, so the $59 launch bundle is 60% off.
  • Licence keys (v1): offline-verifiable keys unlock tier caps in the tool. Production minting is Ed25519 via the Paddle webhook (built, awaiting the go-live steps).
  • Single source of truth: pricing.yaml regenerates the caps in the tool and the prices on the site — they can no longer drift apart.

v1.2 — deleted diff, replay text, capped free tier

  • Deleted-only diff, two ways: compare two exports, or check a handle's captures live — live / deleted / unknown, with unknown never counted as deleted.
  • Replay text fetch: post text pulled from the archived replay, after oEmbed and snapshot meta.
  • Archive fallback links on every result (archive.today, Ghostarchive).
  • Capped free tier: free 25 captures, 3 networks, 3 batch targets, text for 5 posts; caps printed on every run.
  • SEO + Cloudflare hosting: title/meta/OG/JSON-LD, robots.txt, sitemap, the SEO check (12/12), and the Pages deployment.

Built, not yet live

These are built and tested locally, but need human go-live steps before they work on the deployed site — so they are not promised as shipped:

  • Sign-in (Clerk) + Turnstile bot check — the app, keys, and database migration are human steps.
  • Paddle checkout → licence minting → email — the webhook, Ed25519 minting, and Resend email are built; the Paddle account, products, and secrets are human steps, and the $1 sandbox purchase test is still to run.
  • Server-side evidence counting + Stripe billing portal (test mode) — built; database migrations not yet applied live.
  • Per-subdomain branding + the guides on this page — built locally, awaiting the batched push.
